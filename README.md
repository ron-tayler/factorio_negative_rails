# Negative Rails

Мод для Factorio 2.0 и 2.1. Наземные отрицательные рельсы позволяют записать в чертёж,
какие сегменты существующего перекрёстка следует разобрать.

## Сборки для разных версий Factorio

- Factorio 2.0: `dist/negative_rails_1.0.2.zip` — проверена в Factorio 2.0.77
  без Negative Space и вместе с Negative Space 0.2.3.
- Factorio 2.1: `dist/factorio-2.1/negative_rails_1.0.3.zip` — отдельный релиз
  с той же функциональностью. В `info.json` изменены `version` на `1.0.3`, `factorio_version` на `2.1`
  и зависимость на `base >= 2.1.0`. Код, локализации и thumbnail совпадают со
  сборкой для 2.0. Ключевые используемые API сверены с документацией 2.1;
  запуск и игровые тесты в Factorio 2.1 пока не проводились.

На портале релизы для разных веток игры используют разные номера.
В обе сборки добавлена необязательная зависимость `? negative_space`.
Negative Rails работает самостоятельно; Negative Space дополняет его
демонтажом светофоров и других объектов. Обработка светофоров в Negative Rails
не добавляется.
Поле `factorio_version` задаёт одну ветку игры, диапазоны в нём не поддерживаются.

## Сборка архивов

Исходники релизов находятся в `mods/negative_rails_1.0.2` (Factorio 2.0)
и `mods/negative_rails_1.0.3` (Factorio 2.1). Собрать оба ZIP с описанием,
thumbnail и лицензией можно командой:

```powershell
.\tools\build.ps1
```

Готовые архивы появляются в `dist`. Эта папка и тестовые карты не входят
в Git. Тег `1.0.3` обозначает состояние проекта с обоими релизами.

## Установка и использование

1. Скопировать архив для своей версии игры в `%APPDATA%\Factorio\mods`.
2. Включить Negative Rails и перезапустить игру.
3. Построить образец нового перекрёстка на свободном месте.
4. Нажать Shortcut «Отрицательные рельсы» или `Ctrl+Shift+R`.
5. Проложить розовые отрицательные пути штатным планировщиком рельсов.
   Они обозначают конкретные сегменты старого перекрёстка, которые нужно удалить.
   На свободном месте обычное размещение оставляет розовые призраки-маркеры
   для подготовки чертежа. Они не образуют настоящий железнодорожный путь.
6. Скопировать обычные и отрицательные рельсы в один чертёж.
7. Совместить чертёж со старым перекрёстком и разместить в режиме
   **сверхпринудительного строительства** (по умолчанию `Ctrl+Shift+ЛКМ`).
8. Роботы разберут отмеченные пути и построят обычные призраки из чертежа.

Рецепта и исследования для отрицательных рельсов нет. Кнопка выдаёт в курсор
призрак предмета-планировщика: ресурсов не требуется, мгновенная замена
настоящего рельса предметом из курсора исключается.

Призраки-маркеры принадлежат отдельной дружественной силе без роботов:
строительная сеть игрока не берёт их в работу и не сообщает о нехватке
предметов для них. Невидимый служебный объект обеспечивает копирование.
В готовом чертеже он заменяется соответствующим отрицательным рельсом;
служебные данные и дубли в чертёж не попадают. Construction Planner Continued
для работы нашего мода устанавливать не требуется.

При обновлении реальные отрицательные рельсы предыдущих версий автоматически
переводятся в защищённые призраки. Если они соединяли действующую магистраль,
на их месте возникнет настоящий разрыв — его нужно заполнить обычными рельсами.

## Прямой демонтаж без чертежа

Взять инструмент через Shortcut / `Ctrl+Shift+R`, проложить отрицательный путь
поверх удаляемой ветки в режиме сверхпринудительного строительства
(`Ctrl+Shift+ЛКМ`). Совпадающие рельсы получают приказ на снос и сохраняются
до обычной разборки. После разборки возвращается ресурс обычного рельса.
При ручной прокладке на свободном месте остаются защищённые призраки-маркеры,
включая обе формы дуг и полудиагонали. Это работает и в сверхпринудительном
режиме. Выбор поведения зависит от совпадения конкретного сегмента:
совпадает положение, форма и направление настоящего рельса — демонтаж;
не совпадает — новый призрак для подготовки чертежа.

Таким образом, одна прокладываемая линия может одновременно помечать старые
сегменты на снос и оставлять новые призраки для чертежа. Для наложения на
существующий путь использовать сверхпринудительное размещение.
При размещении готового чертежа отрицательные сегменты по-прежнему являются
одноразовыми инструкциями: на пустом месте они исчезают.

## Проверенное поведение

Игровые проверки в Factorio 2.0.77:

- Мод загружается в движок.
- Совпадающий отрицательный рельс из сверхпринудительно размещённого чертежа
  вызывает Upgrade; мод отменяет его и выдаёт Deconstruction исходному рельсу.
- Проверены прямой сегмент, полудиагональ, дуги A/B и четыре поворота чертежа.
- Соседний прямой путь и прямой путь, пересекающий удаляемый сегмент,
  сохраняются в тестовом примере.
- Обычные рельсы смешанного чертежа оставляют задания на строительство.
- Отрицательные призраки на пустом месте исчезают.
- Явный приказ Upgrade в отрицательный рельс также превращается в демонтаж.

Проверки выполняются через игровой API размещения чертежа в headless-режиме.
В версии 0.1.2 обработчик ручного маркера дополнительно проверен с игроком
на изолированной копии сохранения. Проверено сохранение исходного рельса,
пересекающегося пути и возврат ресурса после добычи.
Нативная прокладка из курсора-призрака не воспроизводится методом
`LuaPlayer.build_from_cursor` в Factorio 2.0: в тесте уведомление о ручном
маркерe моделируется событием, а Upgrade проверяется размещением чертежа.
Прокладка мышью, зеркальное отражение, Undo/Redo и полный цикл строительных
роботов ещё требуют проверки в интерфейсе игры.

В версии 0.1.3 дополнительно проверены призрачный формат, копирование в чертёж
без дублей, отсутствие настоящего отрицательного пути, сохранение маркера
рядом с робопортом и роботами на протяжении 1800 игровых тиков, отсутствие
предупреждений игрока для этого маркера и совместное удаление пары объектов.

В версии 0.1.4 исправлена ручная прокладка дуг: обе формы остаются призраками
на свободном месте, копируются в чертёж, совпадающая обычная дуга получает
приказ на снос, а прямой рельс под другой формой отрицательного пути сохраняется.
Обработчик не требует предварительного события `on_pre_build`, которое штатный
планировщик рельсов может пропускать.

## Ограничения

- Только современные наземные рельсы; эстакады, опоры, рампы и старые рельсы
  Factorio 1.1 не поддерживаются.
- Для наложения использовать сверхпринудительное размещение. Обычное и
  принудительное размещение могут пропустить совпадающий отрицательный сегмент.
- Сверхпринудительное размещение сохраняет стандартное поведение Factorio:
  мешающие постройкам объекты тоже могут получить приказ на снос.
- Отрицательные пути при подготовке образца являются защищёнными призраками:
  по ним не ездят поезда и они не соединяют железнодорожные блоки.
- Инструмент использует курсор-призрак. Если он уже был в курсоре при
  обновлении с предыдущей версии, обработчик обновления переведёт его в
  безопасный режим; также можно повторно нажать Shortcut.
- История отмены после преобразования Upgrade в демонтаж пока не проверена.

## Исходники и тесты

`mods/negative_rails_1.0.2/data.lua` — собственные рельсовые прототипы,
предмет-планировщик и Shortcut.

`mods/negative_rails_1.0.2/control.lua` — выдача предмета, обработка Upgrade
и удаление временных отрицательных призраков.

`tests/run.ps1` — изолированный игровой тест. Все его моды, конфигурация,
карта и логи размещаются в `test-runtime` внутри проекта. Рабочие моды и
сохранения пользователя не изменяются. Дополнительный параметр `-PlayerSave`
копирует указанную карту в `test-runtime` для проверки обработчиков с игроком.

```powershell
.\tests\run.ps1 -Factorio 'F:\SteamLibrary\steamapps\common\Factorio\bin\x64\Factorio.exe'
```
